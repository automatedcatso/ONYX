# Code of Conduct

Contributors must communicate respectfully, review ideas rather than identities, protect private user and moderator information, and avoid harassment, discriminatory language, sexual content, threats, doxxing, or retaliation.

Project maintainers may edit, remove, or reject contributions and restrict participation when behavior harms contributors, users, or the security of the project. Good-faith technical disagreement is welcome; personal attacks are not.

Report conduct concerns privately through the repository owner. Include only the information necessary to assess the incident.
