# Support

Use GitHub issues for reproducible bugs and feature proposals that contain no private data. Use private vulnerability reporting for security concerns.

Before opening an issue, run:

```bash
npm test
npm run verify:env -- --production
```

Include the commit hash, deployment environment, browser, exact route, expected behavior, actual behavior, and redacted logs. Never post service keys, SMTP credentials, access tokens, user emails, private messages, or moderation evidence.
